# 콘텐츠제작 페이지의 Pixeling 연결 상태

이 변경은 콘텐츠제작 페이지와 전용 구성요소·API·데이터·마이그레이션만 대상으로 합니다. 다른 페이지·헤더·기존 결제 코드는 수정하지 않습니다.

2026-11-13 설치된 Pixeling Desktop 1.1.8의 native_preset_library.json에서 공개된 공용 103개와 픽셀링 40개의 ID·이름·버전·크기·분류를 읽었습니다. 실제 파일의 SHA-256을 확인한 썸네일 82개를 포함합니다. 개인 프리셋, 제작 프롬프트, 계정 정보, 토큰, 로컬 경로, 템플릿 코드는 내보내지 않습니다. 이는 시점별 스냅샷이며 실시간 동기화가 아닙니다. 검증한 영상 25개는 운영자의 재배포 권한 확인과 공개 게시 승인에 따라 원본과 동일한 전체 길이, 최대 720px의 MP4 미리보기로 포함합니다. 25개 전체 재생용 영상은 원본 길이 대조와 전체 디코딩 검사를 통과했습니다. 118개는 원본이 없어 기본 재생 목록에서 제외하고, 영상 미등록 필터에서 별도 표시합니다. 고객 화면에는 제공자명 대신 BESTSNS 콘텐츠 스튜디오와 추천 프리셋으로 표시합니다.

## 실행 가능한 범위

- 프리셋 탐색·검색·분류·선택, 고객의 요청 원문 보존, 회원별 주문 내역
- 프리셋 클릭 시 모달 영상 재생, 영상이 없는 프리셋은 썸네일과 준비 상태 표시
- 대화창 파일 선택·끌어놓기: 최대 8개, 각 100MB, 합계 300MB의 영상·이미지·음원·PDF·TXT
- 확인 후 비공개 버킷 업로드, 서버에서 크기·파일 헤더 확인 후 접수 완료
- 운영자 작업 파일(JSON) 및 고객 원문 복사
- 운영자가 Pixeling에서 같은 ID·버전을 선택해 수동 실행
- 운영자가 제작 시작을 확인하고 결과 MP4를 주문에 업로드
- 해당 회원만 완료 결과의 만료 링크 조회·다운로드, 완료 주문 기반 수정 요청

## 아직 자동화되지 않은 범위

Pixeling의 로컬 preset HTTP API는 동일 출처와 host session을 검사하고 일부 작업은 호스트 전용입니다. 외부 서비스용 안정적인 주문 실행 API·완료 콜백은 확인되지 않았습니다. 이 제한을 우회하거나 내부 세션을 추출하지 않습니다. 현재 PC에서 자동으로 새 채팅 생성·프리셋 선택·요청 입력·완성 파일 회수까지 수행하는 어댑터는 없습니다. 화면 클릭 자동화를 운영용으로 검증하지 않았습니다. 현재 구현을 완전자동 제작 서비스로 판매하지 마세요.

프리셋 연결은 이름만이 아닌 ID·버전으로 확인해야 합니다. 사용 가능한 공식 자동화 방법이나 제공자 지원이 확보되면 서명된 주문 수신, 일회성 작업 인수, 주문별 작업 폴더·대화 ID, 결과 검증·업로드, 실패 재시도 시 중복 제작 방지를 갖춘 별도 PC 작업자를 연결해야 합니다.

## 활성화

1. 기존 콘텐츠 저장소 구성 후 `20261113_content_pixeling.sql`, `20261113_content_studio_attachments.sql`, `20261113_content_studio_projects_presets.sql`을 순서대로 적용합니다. 추가 SQL은 전용 비공개 `content-studio-input` 버킷과 첨부·진행 기록 컬럼을 생성합니다.
2. 기본적으로 `CONTENT_PIXELING_REQUESTS_ENABLED`는 설정하지 않습니다. UI는 실제 프리셋을 탐색하고 요청을 작성할 수 있지만 제출하지 않습니다.
3. 운영자가 수동 제작을 맡는 시범 접수를 명시적으로 운영할 때만 `CONTENT_PIXELING_REQUESTS_ENABLED=true`를 설정합니다. 화면에 수동 운영자 접수·무과금임을 표시합니다. 기존 유료 제작 흐름으로 몰래 우회하거나 기존 크레딧을 차감하지 않습니다.
4. 운영자 로그인 후 콘텐츠제작 페이지의 ‘운영자 주문 관리’를 켜서 주문을 처리합니다. 완료 MP4는 150MB 이하이며 원본 MP4 헤더와 실제 업로드 크기를 서버에서 확인합니다. 파일의 내용·음성·품질은 운영자가 검수해야 합니다.

작업 상황: 파일 업로드 바이트 기반 진행률을 표시합니다. 회원은 15초마다 자기 주문의 상태와 운영자가 등록한 회원용 작업 문구를 조회합니다. 외부 제작 프로그램의 로그를 자동 수집하거나 모델의 내부 추론·비공개 프롬프트를 노출하지 않습니다.

미연결: 제작 프로그램의 실시간 로그 자동 수집, 실시간 카탈로그 동기화, 이 새 주문의 결제·SNS 게시. 기존 기능은 삭제하지 않았지만 새 Pixeling 주문과 연결하지 않았습니다.

검증: `node --test tests/content-pixeling.test.cjs`, `npm run build`.

카탈로그 갱신은 `python scripts/content-pixeling/export-catalog.py <픽셀링 라이브러리 JSON 경로> netlify/data/content-pixeling-catalog.json`으로 수행합니다. 프로그램 파일을 수정하지 않는 읽기 전용 작업입니다.


## 프로젝트와 운영자 프리셋

새 영상 만들기는 독립된 프로젝트 ID를 생성합니다. 작성 중인 텍스트와 선택 스타일은 계정별 브라우저 저장소에 저장하며, 첨부 초안 파일은 영구 저장하지 않습니다. 전송된 대화는 서버의 회원 소유 프로젝트 ID로 묶습니다. 다른 프로젝트와 회원의 대화가 섞이지 않도록 검사합니다.

운영자는 콘텐츠제작 페이지의 전용 관리 영역에서 MP4 전체 영상(300MB 이하), 설명, 비공개 제작 지침을 등록할 수 있습니다. 브라우저 재생 확인 후 썸네일을 생성하고, 서버에서 업로드 크기와 파일 헤더를 검증한 뒤 공개합니다. 비공개 지침은 공개 목록·회원 API에 포함하지 않으며 운영자 작업 전달에만 포함합니다. 운영자 영상 공개·비공개 및 지침 수정 기능을 제공합니다.
