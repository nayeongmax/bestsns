BESTSNS 제작 연결 · 자동화 검증판 0.2

운영자 PC에만 설치합니다. 회원은 사이트에서 사용합니다.
이 버전은 주문마다 시작 확인/완성본 확인을 요구하지 않습니다.

자동 처리 흐름
1. 최초에 사이트 주소와 운영자 PC 연결키를 입력하고 '연결 / 자동 처리 시작'을 누릅니다.
2. 주문 1건을 수신하면 프리셋 ID·버전을 검증하고 고객 요청·첨부 자료·운영자 지침을 자동 전달합니다.
3. 픽셀링에 주문별 final.mp4와 output.ready.json 완료 기록을 만들도록 지시합니다.
4. 완료 기록의 주문 번호·일회성 값·SHA-256, 파일 안정화(20초), MP4 구조, 영상 스트림과 전체 디코딩 성공을 검사합니다.
5. 통과한 파일을 자동 업로드하고 사이트 완료 상태를 기록합니다. 다음 주문을 자동으로 받습니다.
6. 연결 후 설정을 저장하면 다음 프로그램 실행 시 자동 연결합니다. '자동 처리 일시정지'는 이 자동 연결도 해제합니다.

설치 및 사전 설정
- BESTSNS-Setup.exe: 설치 및 시작 메뉴 바로가기. Windows 부팅 시 자동 실행은 설정하지 않습니다.
- BESTSNS-Studio-Bridge.exe: 설치 없이 실행 가능.
- 기존 콘텐츠 SQL 다음에 20261113_content_desktop_worker.sql 적용이 필요합니다.
- 사이트 CONTENT_DESKTOP_WORKER_ENABLED=true 및 주문 수신 설정이 필요합니다.
- 콘텐츠 작업실 운영자 화면에서 PC 연결키 발급 후 입력합니다. 키는 90일 후 만료됩니다.
- 로그인된 픽셀링과 제작 공급자 연결, 프리셋 동기화가 필요합니다.
- ffmpeg/ffprobe는 PC의 PATH 또는 픽셀링 설치 폴더에서 자동 탐색합니다. 없는 경우 시작을 중단합니다.
- PC를 켜고 Windows 사용자 세션 및 픽셀링을 유지해야 합니다. 잠금·절전·앱 종료는 제작을 방해할 수 있습니다.
- 자동 처리 중 픽셀링에서 다른 대화를 조작하지 마세요.

오류와 복구
- 일시적인 통신 오류는 최대 5회 지수 간격으로 재시도합니다. 제작 요청을 다시 보내는 재시도는 하지 않습니다.
- 저장된 대화 연결을 확인한 submitted/uploading 작업은 재시작 후 감시/전달을 이어갑니다.
- 전송 직전·직후의 상태를 확정하지 못하면 재전송하지 않고 중단합니다.
- 파일이 없거나 완료 기록이 없으면 기다립니다. 4시간을 넘거나 잘못된 파일이면 확인 대상으로 중단합니다.
- 업로드 재시도는 같은 주문·같은 파일 해시만 허용합니다. 서버 완료 응답이 유실되어도 중복 제작하지 않습니다.
- 픽셀링 자체의 추가 질문/권한 팝업/공급자 오류를 임의로 승인하지 않습니다. 완료되지 않은 주문은 시간 초과로 중단합니다.
- 정상 주문에는 운영자 확인 단계가 없습니다. 구조 변경이나 실패 등 예외 상황에는 복구가 필요할 수 있습니다.

검증 범위와 한계
- 화면 좌표를 사용하지 않고 UI 이름·종류와 프리셋 ID·버전을 확인합니다. 모든 앱 업데이트 호환성을 보장하지 않습니다.
- 자동 파일 검사는 손상·불완전 파일 방지용입니다. 편집 의도, 자막 정확도, 미적 완성도까지 보장하는 검사는 아닙니다.
- 실제 회원 주문 → 픽셀링의 전체 영상 생성 → 사이트 다운로드까지의 운영 환경 통합 시험은 아직 완료되지 않았습니다.
- 현재 프로그램·서버 코드와 자동화 시험을 제공한 상태이며 운영 DB 변경, 주문 활성화, 공급자 키 입력을 수행한 것은 아닙니다.
- 설정과 작업 기록은 Windows 사용자별 암호화로 저장하고, 영상과 첨부는 주문별 폴더에 저장합니다.
- 기존 0.1 실행 파일을 종료한 다음 설치하세요.
