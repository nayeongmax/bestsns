BESTSNS 제작 연결 · 검증판 0.1

운영자 PC에만 설치합니다. 회원 PC에는 설치하지 않습니다.
BESTSNS-Setup.exe는 설치 및 시작 메뉴 바로가기를 만듭니다.
BESTSNS-Studio-Bridge.exe는 설치 없이 실행할 수도 있습니다.
Windows 시작 시 자동 실행 또는 방화벽/보안 설정 변경은 하지 않습니다.

현재 상태
- UI 이름·종류로 픽셀링을 찾는 Windows UI Automation 방식입니다. 저장된 화면 좌표나 임의 클릭을 사용하지 않습니다.
- 프리셋 이름만 비교하지 않고 로컬 목록의 ID·버전을 확인합니다.
- 실제 화면이 달라지거나 요소가 중복되면 중단합니다. 모든 미래 업데이트에 대한 호환성을 보장하지 않습니다.
- 자동화 어댑터의 실제 전체 영상 제작/회원 전달 시험은 아직 완료하지 않았습니다. 운영자 검토 단계가 있는 검증판입니다.
- 설정과 작업 기록은 Windows 사용자별 DPAPI로 암호화됩니다. 첨부와 완성 영상은 내 PC의 주문별 폴더에 저장됩니다.

사이트 준비 (개발/운영 설정)
1. 앞선 콘텐츠 전용 SQL 다음에 20261113_content_desktop_worker.sql을 적용합니다.
2. Netlify의 CONTENT_DESKTOP_WORKER_ENABLED=true를 설정해야 PC가 주문을 가져옵니다.
3. CONTENT_PIXELING_REQUESTS_ENABLED는 실제 제작/반환 검증 후 켭니다. 요금은 미정이며 결제는 연결되지 않았습니다.
4. 콘텐츠 작업실 운영자 화면의 '운영자 PC 연결'에서 키를 발급합니다. 이 키는 회원에게 공유하지 않습니다.

PC 사용 순서
1. 픽셀링을 로그인된 상태로 열어 둡니다. 제작에 필요한 프리셋 및 각 공급자 연결도 준비되어야 합니다.
2. 제작 연결 프로그램에서 올바른 사이트 주소와 PC 연결키를 입력합니다. 미리보기/운영 환경 키를 혼용하지 마세요.
3. '픽셀링 구조 진단'으로 이름·버튼 실행·입력 기능을 확인합니다.
4. '사이트 연결 / 주문 받기'를 누릅니다. 최초 버전은 한 번에 한 주문만 받습니다.
5. 요청 내용을 확인하고 '검토 후 제작 시작'을 누릅니다. 프리셋을 찾고 고객 원문·운영자 지침·자료 경로를 픽셀링에 전달합니다.
6. 작업 중에는 픽셀링의 다른 대화로 이동하거나 직접 입력하지 않는 것을 권장합니다.
7. 최종 파일이 주문 전용 폴더의 final.mp4로 저장되면 '완성본 확인 / 전달'을 누릅니다.
8. 열린 영상이 해당 주문의 완성본인지 끝까지 확인한 후 전달을 승인합니다. SHA-256이 일치한 동일 파일만 사이트 완료로 처리합니다.

중단/복구
- 연결이 끊겨도 이미 실행한 주문을 자동 재전송하지 않습니다.
- 프로그램 재시작 시 기존 주문을 복원합니다. 진행 중 주문을 다시 만들지 말고 픽셀링에서 상태를 확인하세요.
- '구조를 찾지 못함', 프리셋 불일치, 새 대화 연결 실패는 운영자 확인이 필요합니다.
- 자동으로 대기열 승인/회원 최종 전달을 하지 않습니다. 초기 실제 주문 시험이 끝나기 전에는 무인 운영용으로 사용하지 마세요.
- 다른 영상 파일이나 최신 파일을 임의로 찾아 업로드하지 않습니다. 주문 폴더의 지정된 final.mp4만 취급합니다.
- 연결키는 90일 후 만료됩니다. 운영자 화면의 연결 해제로 폐기할 수 있습니다.

이번 배포에서 실제 운영 DB 변경, 운영 사이트 주문 활성화, 픽셀링 API/공급자 키 입력은 수행하지 않았습니다.
